How to Deploy Any Task on Vercel

Each task is equipped with autonomous build scripts. You can deploy each project independently in 3 quick steps:

1
Import in Vercel
In your Vercel Dashboard, click Add New > Project and select Internship-Ezitech.
2
Set Root Directory
Click Edit next to Root Directory and pick the task folder (e.g. Task 5/ecommerce_app or Task 7).
3
Deploy & Launch
Click Deploy. Vercel will automatically run the customized Flutter build pipeline and provide your live URL!
